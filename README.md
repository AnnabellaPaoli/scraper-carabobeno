# 📰 Scraper de Noticias - El Carabobeño

![Python](https://img.shields.io/badge/Python-3.8%2B-blue)
![Status](https://img.shields.io/badge/Status-En%20Desarrollo-orange)

Una herramienta de CLI (Linea de Comandos) desarrollada en Python para extraer, categorizar y analizar noticias del diario digital *El Carabobeño*. Este proyecto permite descargar titulares y enlaces de diferentes secciones y realizar un análisis básico de frecuencia de palabras.

## 🚀 Características Principales

- **Menú Interactivo:** Interfaz de consola amigable con arte ASCII y colores.
- **Categorización:** Extracción de noticias por secciones (Deportes, Gran Valencia, Universidad, Internacional, Nacional).
- **Evasión de Bots:** Uso de `User-Agents` rotativos para simular navegación humana.
- **Persistencia de Datos:** Guardado automático de la información extraída en archivos CSV.
- **Análisis de Texto:** Conteo de palabras clave más frecuentes (excluyendo *stopwords*).
